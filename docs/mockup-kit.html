颜色使用规则：
  • 所有"墨色 / 黑"统一使用 color-ink (#1a1a1a)，禁止使用纯黑 #000000（包括图标 stroke、文字 fill）。
  • 所有边框统一使用 color-border（值同 ink），通过 var(--border) token 应用。
  • 表面/背景仅在 surface / bg / light 三档中选择，不要随意引入新的浅色。
  • 价格颜色（电商场景）：售前展示（PDP / 购物车 / 收银台 / 商品列表）用 color-warning (#e65100) 突出转化；售后展示（订单列表 / 订单详情 / 余额 / 退款）一律用默认 color-ink。
Theme

点击下方任一色块即可切换 demo 整体主题色（覆盖 --color-accent / --color-accent-bg / --color-accent-fg）。Default 使用规范的 accent 蓝；其它主题为可选项，配套的 BG 是主色 ~10% 不透明度的等效色。Green / Purple / Pink 主题下按钮文字保持白色以提升可读性，Yellow 用墨色文字。
注：<a> 超链接使用独立的 --color-link token，始终保持默认 accent 蓝，不随主题变化。

When to use which
shadow 大容器 / 浮层 — 里面能再放别的组件，或悬浮在内容之上。
card · list · table-wrap · sidebar-nav · navbar · tabbar · modal · bottom-sheet · dropdown-menu · popover · toast · phone-frame · browser-frame
shadow-sm 小型交互元件 / 表单控件 — 自己就是被装进去的最小单位。
btn · page-btn · icon-item · inp · checkbox · radio · toggle · slider-thumb · avatar · tag · step-circle · alert
一句话决策树： 里面能再放组件 → shadow；自己是原子单位 → shadow-sm。判断维度是层级关系而非大小（例如 alert 视觉较大，但属于"嵌入页面的提示条"，所以用 shadow-sm）。

使用规则（强制）
  • 位置：必须作为 <body> 直接子元素或顶层布局节点放置；禁止放在 overflow:hidden / 限定高度的祖先容器内，否则 sticky 失效。
  • 定位：使用 position:sticky;top:0;z-index:100；禁止改用 fixed（需手动占位、且与 modal/dropdown 的 z-index 易冲突）。
  • 边界：通栏铺满视口，仅保留 2px 下边线 作为硬分隔；阴影改为 0 3px 0 ink，仅向下投射，禁止恢复四向边框 / 圆角。
  • 断点收纳： ≤1024 → 收紧 padding/gap 与搜索宽度； ≤768 → 隐藏 .navbar-menu，让位右侧 Slot； ≤480 → 进一步隐藏 .search-wrap，仅保留品牌 + 关键 Slot 控件。
  • 结构：左侧 .navbar-brand + .navbar-menu；右侧 .navbar-slot（搜索 / 语言切换 / 图标按钮 / 头像等）。Slot 通过 margin-left:auto 自动靠右。
  • 页面让位：吸顶导航高度为 56px。页面内其他 sticky 元素（如侧栏 Order Card）需将 top 设置为 calc(56px + sp4) 以避免被遮挡。
  • 实色变体：默认白底之外提供 .navbar-solid（黑底，品牌色跟主题 accent，菜单文字白），用于黑金 / 高端 / 游戏类品牌。 规则：实色头部下，.btn-ghost 图标按钮的颜色已被自动反相，无需自行覆写；其余 slot 内组件（btn / inp / avatar）保持白底原样以与背景形成对比。
